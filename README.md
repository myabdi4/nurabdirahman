# Nur Abdirahman — Personal Portfolio

A clean, minimal personal portfolio built with React and Vite. Features a contact form connected to Supabase, dark mode, scroll animations, and full mobile responsiveness.

🔗 **Live site:** [nurabdirahman.vercel.app](https://nurabdirahman.vercel.app)

## Tech Stack

- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS v4
- **Database:** Supabase (contact form)
- **Routing:** React Router v6
- **Deployment:** Vercel

## Sections

- Hero
- About + Skills
- Projects
- Experience
- Education + Certifications
- Contact (form connected to Supabase)

## Running Locally

```bash
git clone https://github.com/myabdi4/nurabdirahman.git
cd nurabdirahman
npm install
npm run dev
```

Create a `.env` file in the root:

VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
